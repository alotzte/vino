# Мини-приложение в MAX

Внутри чат-бота MAX открывается то же React-приложение, что и на `app.nektarum.ru/vino/`.
Отдельной сборки нет: фронтенд видит непустую `window.WebApp.initData` и включает
интеграцию, в обычном браузере ничего не меняется.

## Что где

| Файл | Что делает |
|---|---|
| `frontend/index.html` | подключает MAX Bridge (`https://st.max.ru/js/max-web-app.js`) в `<head>` до бандла, иначе `window.WebApp` не успеет появиться |
| `frontend/src/max.ts` | единственное место, где используется `window.WebApp` |
| `App.tsx` | `WebApp.ready()`, системная кнопка "Назад", вибрация на результат скана, разбор диплинка после возрастного гейта |
| `CardScreen.tsx` | "Поделиться в MAX" с диплинком на карточку, ссылка на vino-svoe.ru через `WebApp.openLink` |
| `api.ts` | шлёт заголовок `X-Max-Init-Data` (через `encodeURIComponent`, заголовок должен быть latin-1) |
| `backend/app/auth.py` | проверяет подпись initData токеном бота. Если она верна, профиль привязан к `max:<user.id>` и общий для всех устройств, иначе используется `X-Device-Id` |

Скрипт оценки не шлёт ни `X-Device-Id`, ни `X-Max-Init-Data`, на него интеграция не влияет.

## Диплинки

Формат `https://max.ru/<бот>?startapp=<payload>`, payload из символов `[A-Za-z0-9_-]`,
до 512 символов.

| payload | что открывает |
|---|---|
| `w_<slug>` | карточку вина (все slug каталога подходят, самый длинный 139 символов) |
| `catalog`, `map`, `profile` | соответствующую вкладку |

В браузере тот же payload работает через `?startapp=`, так что диплинки можно проверить
без MAX: `https://app.nektarum.ru/vino/?startapp=w_dnk-alleli`.

## Подключение

1. Создать бота на платформе MAX для партнёров (business.max.ru), раздел "Чат-боты".
   Для этого нужен статус юрлица, ИП или самозанятого, резидента РФ. Скопировать токен
   и имя бота.
2. Прописать переменные в `.env` рядом с `docker-compose.yml`:
   ```
   VINO_MAX_BOT_TOKEN=<токен бота>
   VINO_MAX_BOT_NAME=<имя бота без @>
   ```
   Без токена приложение работает, но профиль привязан к устройству, а не к пользователю
   MAX. Без имени бота "Поделиться" отдаёт обычную веб-ссылку.
   `VINO_MAX_INIT_DATA_TTL` (по умолчанию 86400 с) задаёт срок жизни подписи, `0`
   отключает проверку срока.
3. Выполнить `./scripts/deploy.sh`.
4. В настройках бота указать URL мини-приложения `https://app.nektarum.ru/vino/` и текст
   кнопки "Открыть". После этого в чате с ботом появится кнопка запуска.

## Что не проверено на устройстве

Эмулятора MAX нет, поэтому эти вещи проверены только по коду:

- выбор фото и камера (`<input type="file" capture>`) в webview MAX на iOS и Android;
- что `initData` приходит URL-кодированной строкой, как сказано в документации. Если
  подпись не сойдётся, `/api/me` из MAX будет отдавать новый профиль на каждом устройстве;
- отступы под шапку MAX (в вёрстке уже есть `env(safe-area-inset-*)`).
